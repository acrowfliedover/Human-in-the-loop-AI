Krippendorff's alpha: Module 7 visitor-intent labels
Source: Module_7_assignment/labeled_visitor_intent.csv
Raters: annotator_1 through annotator_5 (final_label excluded)
Items: 30. Categories: Buyer, Seller, Renter, Other. Distance: nominal.

alpha = 1 - (D_o / D_e)

n = 150 codes. Category totals: Buyer 87, Seller 9, Renter 19, Other 35.
Observed coincidences on the diagonal: Buyer 74, Seller 5.5, Renter 9, Other 18.5.

D_o = (150 - 107) / 150 = 43/150
D_e = (150^2 - (87^2 + 9^2 + 19^2 + 35^2)) / (150 × 149)
    = (22500 - 9236) / 22350
    = 13264/22350

alpha = 1 - (43/150) / (13264/22350) = 6857/13264 = 0.517

Agreement is above chance and well short of Krippendorff's 0.800 reliability line (0.667 is the floor he allows for tentative conclusions). Alpha is the appropriate summary here because it is one coefficient for any number of raters, it still applies when some ratings are missing, and the same formula accepts nominal, ordinal, or interval distances. Cohen's kappa is defined for two raters only, so five annotators would have to be collapsed into separate pairs. Fleiss's kappa allows multiple raters, but the usual formula requires the same number of ratings on every item and does not reduce to Cohen's kappa when there are two raters.
